# fantasy_Dungeon

既存のファンタジーストラテジーゲームから独立して開発する、シナリオ型ダンジョンRPGの新プロジェクトです。

## 戦闘ルールを試す

このリポジトリには、ブラウザで動く **戦闘ルール確認室** を置いています。

- ソース: [index.html](index.html)
- GitHub Pages公開後のURL: https://siev0000.github.io/fantasy_Dungeon/
- HTML / CSS / JavaScriptのみ。外部ライブラリ・ビルド不要。

### GitHub Pagesで開く手順

1. リポジトリの **Settings → Pages** を開く。
2. **Build and deployment → Source** を **Deploy from a branch** に設定する。
3. **Branch** を **main**、フォルダを **/(root)** にして **Save**。
4. 公開後はPages設定画面の **Visit site** を選ぶ。
5. 公開URL: https://siev0000.github.io/fantasy_Dungeon/

公開処理は数分かかる場合があります。表示されない場合は **Actions** タブのデプロイ結果を確認してください。GitHubでソースファイルを開くだけでは実行画面にはなりません。

### ローカルで開く手順

GitHubの **Code → Download ZIP** でダウンロードし、展開した **index.html** をブラウザで開きます。サーバー起動は不要です。

## スマートフォンでの操作

- 画面上部のヘッダーはスクロールしても固定表示されます。
- 左側のアイコンメニューから「マップ」「行動」「強化」「実行」「移動」「状況」「ログ」「説明」を切り替えます。
- 操作状態（選択カード、敵のHP、ラウンドなど）は画面を切り替えても保持されます。
- PC・タブレットの広い画面は複数パネルの従来レイアウトを維持します。

## 現在確認できる機能

- アクション（斬撃、火球、治癒、移動、突進）
- 強化コマンド（威力強化、射程延長、範囲拡大、機動強化、迅速、強化なし）
- アクション＋強化コマンドの組み合わせ表示と簡易実行
- HEXマップでの敵選択、移動先選択、HPとログ表示
- 移動方式M1・M2・M3の切り替え比較
- 簡易テストシナリオの敵2体撃破判定とリセット

**重要：ルール確認用の仮シミュレーターであり、完成ゲームではありません。**
威力・射程・移動力は仮数値。AP、CT、カード消耗、敵AI、実際のスキル計算は未接続です。**移動方式は未決定**です。

## 開発方針

- 戦闘は **B. 独自カード戦闘型**。
- 初期構想の中心は **アクション＋強化コマンド** の組み合わせ。
- シナリオ進行の参考はグルームヘイヴンだが、独自作品とする。
- **元のストラテジーゲームには変更しない**。
- HEXマップ・洞窟生成・ユニット・クラス・装備・スキルは今後の移植候補で、現在は未移植。
- 仕様の確定・検討中・未確認と、実装済みを区別する。
- 大きな実装変更の前に仕様を確認する。
